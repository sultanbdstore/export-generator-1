🔔 Google Chat Auto-Send Setup
Google Chat webhook URLs can't be called directly from a browser (CORS). This tool sends through a tiny free Google Apps Script relay you deploy once. It forwards your message to whichever webhook you pick, so you can keep multiple Chat spaces/groups and choose the right one per message.
Go to script.google.com → New project → paste the code below → Deploy → "New deployment" → type "Web app" → Execute as Me, who has access Anyone → Deploy → copy the Web App URL into Step 2 below.
function doPost(e) { var data = JSON.parse(e.postData.contents); var options = { method: "post", contentType: "application/json; charset=UTF-8", payload: JSON.stringify({ text: data.text }), muteHttpExceptions: true }; var response = UrlFetchApp.fetch(data.webhookUrl, options); return ContentService.createTextOutput(JSON.stringify({ ok: response.getResponseCode() === 200, code: response.getResponseCode() })).setMimeType(ContentService.MimeType.JSON); }
In each Google Chat space: Space name → Apps → Manage webhooks → Create webhook → copy that URL here (not the chat.google.com room link — the "chat.googleapis.com/v1/spaces/..." one).
Pick which group each message type goes to automatically. Transporter Requisition SMS auto-matches a group with the same name as the transporter if one exists — otherwise pick manually on that card.
